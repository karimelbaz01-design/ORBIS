# ORBIS Console Lab — Alpha 0.1

Static PWA starter for Safari Home Screen and Android browsers. **This is not a PS3 emulator yet.**

## Deploy with GitHub Pages
1. Open repository Settings > Pages.
2. Under Build and deployment choose Deploy from a branch, main, /(root), Save.
3. Visit the published HTTPS URL using Safari; Share > Add to Home Screen.

Features: responsive original interface, locally stored file-name catalog, basic Gamepad API detection, service worker offline cache.

Limitations: no PS3 game execution, no persistence of imported file contents, no controller navigation, no Android native build. Browser PS3 emulation requires extensive research.
